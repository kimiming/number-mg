# 安装部署说明

适用环境：

- Ubuntu 22.x
- 代码已上传到 `/opt/number-manager`
- 数据库使用服务器上的 PostgreSQL 容器
- 目前暂时不使用域名，直接用服务器 IP 访问

---

## 1. 安装 Docker 和 Docker Compose

在 Ubuntu 22.x 上直接执行下面命令：

```bash
sudo apt update
sudo apt install -y ca-certificates curl

sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo "$UBUNTU_CODENAME") stable" | sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

sudo apt update
sudo apt install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

sudo systemctl enable docker
sudo systemctl start docker

docker --version
docker compose version
sudo docker run hello-world
```

如果你想以后不用每次都写 `sudo`，再执行：

```bash
sudo usermod -aG docker $USER
newgrp docker
```

---

## 2. 准备项目环境文件

进入项目目录：

```bash
cd /opt/number-manager
```

如果还没有 `.env`，先复制一份：

```bash
cp .env.example .env
```

编辑 `.env`，至少改掉数据库密码：

```bash
nano .env
```

内容示例：

```env
POSTGRES_DB=phone_admin_system
POSTGRES_USER=phone_admin
POSTGRES_PASSWORD=换成你自己的强密码
JWT_SECRET=换成你自己的长随机字符串
COOKIE_SECURE=false
```

---

## 3. 构建并启动项目

```bash
docker compose up -d --build
```

如果是首次部署，或者数据库刚创建完成，再执行一次迁移：

```bash
docker compose exec app npx prisma migrate deploy
```

检查运行状态：

```bash
docker compose ps
docker compose logs -f app
```

---

## 4. 安装 Nginx

如果你希望直接用服务器 IP 的 80 端口访问，而不是带 `:3000`，就安装 Nginx：

```bash
sudo apt update
sudo apt install -y nginx
sudo systemctl enable nginx
sudo systemctl start nginx
sudo systemctl status nginx --no-pager
```

如果服务器开了防火墙，放行 HTTP：

```bash
sudo ufw allow 'Nginx Full'
sudo ufw status
```

---

## 5. 配置 Nginx 反向代理

创建站点配置文件：

```bash
sudo nano /etc/nginx/sites-available/number-manager
```

把下面内容粘进去：

```nginx
server {
    listen 80 default_server;
    listen [::]:80 default_server;

    server_name _;

    client_max_body_size 100m;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;

        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_set_header X-Forwarded-Host $host;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

启用配置：

```bash
sudo ln -s /etc/nginx/sites-available/number-manager /etc/nginx/sites-enabled/number-manager
sudo rm -f /etc/nginx/sites-enabled/default
```

检查并重载：

```bash
sudo nginx -t
sudo systemctl reload nginx
```

## 6. 访问地址

现在可以直接访问：

- 前台：`http://你的服务器IP`
- 后台：`http://你的服务器IP/admin`

如果你暂时不装 Nginx，也可以直接访问：

- 前台：`http://你的服务器IP:3000`
- 后台：`http://你的服务器IP:3000/admin`

每次 `git pull` 之后，执行：

```bash
cd /opt/number-manager
docker compose up -d --build
docker compose exec app npx prisma migrate deploy
```

## 8. 常见问题

### 8.1 `.env` 还要不要重新复制

如果 `.env` 已经存在，一般不用重新复制。

只有在第一次部署，或者 `.env` 被删掉时，才重新执行：

```bash
cp .env.example .env
```

### 8.2 端口访问不了

检查两点：

```bash
sudo systemctl status docker --no-pager
sudo systemctl status nginx --no-pager
```

如果用防火墙，再确认 80 端口已经放行：

```bash
sudo ufw status
```

### 8.3 容器启动后页面报错

先看日志：

```bash
docker compose logs -f app
```

如果是数据库连接问题，优先检查 `.env` 里的密码是否和 `docker-compose.yml` 一致。
